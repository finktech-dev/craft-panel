Primero, revisá Java

Los servidores de Minecraft necesitan una versión compatible de Java. La versión exacta depende de Minecraft: 1.20.5 o superior suele requerir Java 21; 1.18–1.20.4, Java 17; versiones más viejas pueden necesitar otra versión. Si no querés instalarlo en Windows/macOS/Linux, descargá una versión compatible, descomprimila dentro de tools/java y verificá que exista tools/java/bin/java (o java.exe).

Dejá que se sumen tus amigos

Playit crea una dirección para que puedan entrar desde afuera de tu casa. Es gratis y no tenés que tocar la configuración de tu router.

  1. 1Tocá “Abrir Playit y vincular”.
  2. 2En la página que se abre, iniciá sesión o creá una cuenta y aprobá esta computadora.
  3. 3Volvé a esta pestaña y tocá “Ya la vinculé: verificar”.

Tu contraseña se escribe solamente en Playit. El panel guarda una clave local para conectar este servidor.

Paso 2 de 3: aprobá esta computadora en Playit.

Si todavía no tenés cuenta, podés crearla allí. Cuando Playit confirme la vinculación, volvé a esta pestaña.
