Revisando tu computadora…

Preparar tu computadora

Minecraft necesita un programa llamado Java para funcionar. Lo descargamos por vos y queda dentro de esta carpeta, sin instalar nada en el sistema.

Prefiero instalar Java yo

Descargá Java de Adoptium (Minecraft 1.20.5 o más nuevo usa Java 21) y descomprimilo dentro de tools/java. Después tocá "Ya lo tengo instalado".

¿Cómo quieren jugar?

Podés cambiar de idea más adelante. Esto solo descarga lo que hace falta.

Tipo de servidor

Tiene que ser la misma que usan tus amigos para jugar.

Copiá la carpeta de tu servidor dentro de la carpeta server de Craft Panel. Tiene que tener su archivo de inicio (run.bat en Windows). No vamos a mover ni cambiar tus archivos.

¿Quién puede entrar?

Escribí el nombre de Minecraft de cada amigo, y el tuyo también. Desde que agregues al primero, solo las personas de la lista van a poder entrar.

    Para jugar desde otras casas

    Usamos Playit, un servicio gratis que le da a tu servidor una dirección para compartir. No hace falta tocar el router.

    Listo, ya está conectado.

    1. Tocá "Conectar con Playit".
    2. En la página que se abre, entrá o creá una cuenta y aprobá esta computadora.
    3. Volvé acá y tocá "Ya lo aprobé".
    Otras opciones

    ¿Solo van a jugar conectados al mismo Wi-Fi? Podés saltear Playit; los amigos de otras casas no van a poder entrar.

    ¡Todo listo para jugar!

    La primera vez tarda un poco más porque se crea el mundo. Cuando termine, hacemos una copia automática.
