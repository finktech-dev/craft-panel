WorldEdit deja a los administradores copiar, pegar y rellenar zonas grandes de una vez. El panel no lo instala: si ya lo tenés, acá lo encendés o apagás sin reiniciar.

WorldEdit para administradores: apagado

El cambio tarda un instante.

Opciones avanzadas · qué hace el botón

Al apagarlo se ejecuta /lp group default permission set worldedit.* false y /lp group admin permission set worldedit.* false: el hacha de madera vuelve a ser común y los comandos // quedan bloqueados.

Al encenderlo se ejecuta /lp group admin permission set worldedit.* true, que habilita la varita y los esquemáticos para los administradores.

¿Cómo consigo el enlace del canal?
  1. En Discord, hacé clic derecho en el canal donde querés los avisos y elegí Editar canal.
  2. Andá a Integraciones › Webhooks › Nuevo webhook.
  3. Ponele un nombre y tocá Copiar URL del webhook.
  4. Pegalo acá arriba, tocá Guardar y después Enviar un aviso de prueba.
