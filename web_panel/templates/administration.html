WorldEdit es opcional

Control de permisos para instalaciones que ya usan WorldEdit y LuckPerms.

Este panel no instala WorldEdit ni lo requiere para jugar. Si ya lo instalaste, podés permitirlo o bloquearlo para administradores sin reiniciar el servidor.

• WorldEdit OFF: Ejecuta en vivo /lp group default permission set worldedit.* false y /lp group admin permission set worldedit.* false. La varita y hacha de madera vuelven a ser comunes y los comandos // quedan bloqueados.

• WorldEdit ON: Ejecuta /lp group admin permission set worldedit.* true, habilitando la varita, schematics y construcción al instante para administradores.

💡 ¿Cómo crear un Webhook en Discord en 1 minuto?
  1. En tu servidor de Discord, hacé clic derecho en el canal deseado (ej. #estado-server) y elegí Editar canal.
  2. Andá a la pestaña Integraciones ➔ Webhooks ➔ Nuevo webhook.
  3. Ponele un nombre (ej. Servidor Minecraft) y hacé clic en Copiar URL del webhook.
  4. Pegalo acá arriba y tocá Guardar Cambios y luego Enviar Prueba.
