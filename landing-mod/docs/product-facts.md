# Verified technical decisions

- The project uses Next.js with App Router and TypeScript.
- Its structure separates routes (`src/app`), components (`src/components`), configuration (`src/lib`), and styles (`src/styles`).
- The project uses versions checked on 2026-09-19: Next.js 16.3.5 and React 19.3.0.
- The download link and server address come from public environment variables; they are not mixed into visual components.
